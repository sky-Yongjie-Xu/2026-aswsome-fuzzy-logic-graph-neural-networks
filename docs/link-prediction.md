## 更值得验证的研究问题

### 1．规则能否在 NCNC 缺乏可靠结构证据时纠正补全

研究对象应落到**潜在共同邻居所对应的缺失边**。证据只能来自训练图和可用属性，例如训练度、已有共同邻居、属性相似度及训练图扰动稳定性。

需要回答：零共同邻居、低度、结构—属性分歧场景中，规则是否改善候选排序并减少有害修正？规则是否只学到“全部降权”？与输入信息和参数量相近的 MLP 相比是否仍有价值？这些都是实验问题，不能用“模糊更能处理不确定性”代替证据。

### 2．候选更准，能否带来最终链接预测收益

候选排序、总补全强度和最终目标边预测是不同环节。可以研究把“候选之间如何分配贡献”与“该目标节点对接收多少补全信息”分别建模，避免两个机制重复抑制同一候选。

但普通归一化会丢失候选数量和原有总权重信息，因此要保留总量，并验证禁用/零初始化模块时可精确恢复 NCNC。这个方向是待验证方案；本清单不声称其首次提出。

### 3．模糊优势来自规则形式，还是更多特征和额外训练

至少保留以下平行对照：NCNC、NCNC + 同特征 MLP、NCNC + 固定模糊规则、NCNC + 可学习模糊规则、每个机制单独使用、组合使用。规则、MLP 和辅助目标应共享可用信息及相近调参预算。

## 推荐的证据链

1. **补全任务**：仅遮蔽训练边，生成与真实 NCNC 补全相同的候选；使用实际候选中的困难负边。
2. **候选诊断**：候选 AP、相同候选预算的 Recall/Precision；可靠与不可靠子集提前定义。
3. **纠错诊断**：分别统计原本正确变错误、原本错误被纠正，报告真实边召回与误补数量。
4. **内部作用**：记录进入共同邻居聚合前后的权重、补全总量与规则激活；保持已观测共同邻居分支可追踪。
5. **最终任务**：在固定边划分、固定负边和验证集选择规则下比较 LP AP/AUC；排序指标明确负候选集合。
6. **统计与推广**：配对随机种子和不确定性报告；Cora 之外增加至少其他静态图。已有测试集分析只能算探索性，后续增加新划分/新数据验证。

阈值与候选预算仅用验证集确定。模糊规则或属性处理不能看验证/测试边；FireGNN 一类标签依赖描述量迁移时也不能使用未知标签。结构重建、节点分类或复杂查询结果都不能替代最终 LP 评测。

## 下一步阅读顺序

先精读 GFS-Edge 与 FGAT/FNS，再取得 AFGRL、AFGNN、FGF-GAT 的完整方法与实验部分；随后用 DFS、FL-GNN 检查内部聚合设计，用非神经 SP/路径指标构造简单对照。FuzzyDGL 留作动态拓展，待核条目先补证据，不立即作为强基线结论。
